# 📄 Resume Upload Directory

Upload or replace your PDF resumes directly in this folder on GitHub.

---

### 📂 File Names Required:

| Role | Required File Name |
| :--- | :--- |
| **Data Analyst / Business Analyst (DA / BA)** | `Saniya_Saratkar_Data_Analyst_Resume.pdf` |
| **Data Scientist & AI (DS / AI)** | `Saniya_Saratkar_Data_Scientist_Resume.pdf` |

---

### 🚀 How to Upload or Update in GitHub (Web Browser):

1. Go to this folder: [`public/assets/resumes/`](https://github.com/Saniya1312S/san_portv2/tree/main/public/assets/resumes)
2. In the top right corner, click **"Add file"** ➔ **"Upload files"**
3. Drag & drop your PDF file:
   - Make sure your DA / BA resume is named: `Saniya_Saratkar_Data_Analyst_Resume.pdf`
4. Scroll to the bottom and click the green **"Commit changes"** button.
5. **Done!** GitHub Actions will automatically re-build and publish your website within ~30 seconds.
